# chaibreak/tap

Homebrew casks for apps by Chai Break.

```sh
brew tap chaibreak/tap; brew trust --tap chaibreak/tap; brew install --cask sparescreen && open -a SpareScreen
brew install --cask eyeshift && open -a Eyeshift
```

- **SpareScreen**: use any spare tablet, phone or laptop as a wireless second screen for your Mac. [getsparescreen.com](https://getsparescreen.com)
- **Eyeshift**: keyboard focus follows your eyes: look at a screen, window or split pane and start typing. [sarthakchhabra.com/eyeshift](https://sarthakchhabra.com/eyeshift/)
